Self-hosted email and calendar

A real mailbox for people and agents.

BearMail puts email and calendar on your company domain. Your team uses the web app. Cursor, Claude, and Hermes work in the same mailboxes. Everyone else receives ordinary mail.

Linux x86-64 · your domain · version 0.1.0

What you have when the installer finishes.

One Linux server with systemd. An interactive setup. Mail for people, and a sidecar so agents can use it too.

01

Mail on your domain

SMTP, IMAP, JMAP, and an admin console on a hostname you choose, such as mail.example.com.

02

Webmail and calendar

The team signs in at a second hostname, such as webmail.example.com. Caddy serves HTTPS.

03

Agents on those mailboxes

An MCP sidecar talks JMAP to the same server. Cursor, Claude, and Hermes can use a mailbox you create for them.

04

Mail the world already accepts

When the host blocks port 25, outbound mail leaves through an SMTP relay. Calendar invites travel as normal messages.

People and agents, one mail system.

A person and an agent each get an address on the server you run. Outside recipients stay on ordinary email.

Example addresses

ada@company.com Person
scheduler@company.com Agent

Same server. The agent starts in draft-only mode, with its own API key.

People

They read, write, and schedule in the web app. Sign-in is the mailbox you created in admin.

Agents

Each agent gets a dedicated address, separate from a founder inbox. MCP in this release is Draft v0.1. Sending stays draft-only until you allow it.

Everyone else

They receive normal messages and calendar invites in the mail client they already use.

A short path onto your own server.

A Linux x86-64 machine with systemd, a public address, and a domain. If the provider blocks outbound port 25, have an SMTP relay ready. name.com and Hostinger can be updated by the installer. Any other registrar gets the zone records to publish by hand.

curl -fsSL https://raw.githubusercontent.com/luoxiprovo/bearmail/main/release_install.sh | sudo bash

Add --dry-run to preview the download before anything changes. The quick start covers the agent sidecar after mail is up.

This release, plainly.

Version 0.1.0 is software you host yourself. Managed hosting, parity with large office suites, Docker, Kubernetes, ARM builds, an SLA, and compliance certifications are outside this release. Agents begin in draft-only mode.
